# Video Harness

For a film request, use the [Journey Director skill](skills/journey-director/SKILL.md) and the [agent handoff](docs/CONNECT.md#make-a-film-from-a-repository). The brief can name this repository or a separate product repository. Use the product's README, demo, and an observed workflow to choose what to show. Record the source for captures and claims in the editable project.

Use `node bin/vh.mjs help` for local commands, or start with the `direct-film` prompt if the Video Harness MCP server is connected. Work inside a film project and follow its `AGENTS.md`. Import any supplied LTX clips as video assets with their source details.

Use the [Motion Review skill](skills/motion-review/SKILL.md) on the cut. Inspect frames where viewers need to read text, track a control, or understand a result. Fix visible problems and check the revised frames. Return the editable project and the requested export with a short note about the review.

For toolkit development, follow [CONTRIBUTING.md](CONTRIBUTING.md).
